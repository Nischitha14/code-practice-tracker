Even or Odd

Problem #2 • Java Basics

Problem

Write a Java program that reads an integer and determines whether the number is even or odd.

Explanation

A number is even when it is completely divisible by 2. Otherwise, the number is odd. Use the modulus operator (%) to check the remainder.

Input

The first line contains one integer N.

Output

Print Even if N is even. Otherwise, print Odd.

Example

Sample Input 
8
Sample Output 
Even

Constraints

-109 ≤ N ≤ 109

💡 Hint

Check whether N % 2 == 0.
